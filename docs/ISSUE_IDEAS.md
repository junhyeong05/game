## ⭐ 숫자·글자만 바꾸면 되는 것 (`good first issue`)

- **비행기 색 바꾸기** — `game.js`의 `drawShip()`에서 `#50d9ff`를 원하는 색으로.
- **난이도 조절** — `CONFIG`의 `playerSpeed`, `fireCooldown`, `lives` 값을 바꿔 보고 재미있는 값 찾기.
- **배경 별 개수 늘리기** — `stars`를 만드는 `length: 75` 숫자 바꾸기.
- **시작 화면 문구 다듬기** — `index.html`의 시작 화면 설명 글 고치기.
- **버튼 색 바꾸기** — `style.css` 맨 위 `--accent` 색 바꾸기.

## ⭐⭐ 함수 하나를 고치거나 추가하는 것

- **영어 버전** — 화면의 한국어 문구를 영어로 바꾼 `index.en.html` 만들기.
- **새로운 적 모양** — `drawEnemies()`에서 원 대신 다른 모양(별, 사각형)으로 그리기.
- **총알 두 발 쏘기** — `shoot()`에서 총알을 왼쪽·오른쪽 두 개 만들기.
- **콤보 점수** — 연속으로 맞히면 점수가 더 올라가게 하기.
- **레벨 업 효과음 바꾸기** — `sound.levelUp()`의 음 높이(주파수) 바꿔 보기.

## ⭐⭐⭐ 새 기능 만들기

- **하트 아이템** — 가끔 떨어지는 하트를 먹으면 목숨 +1 (최대 3).
- **보스 적** — 레벨 5마다 체력이 많은 큰 적 등장.
- **파워업** — 아이템을 먹으면 몇 초 동안 연사 속도 증가.
- **화면 드래그로 이동** — 휴대폰에서 캔버스를 손가락으로 끌어서 비행기 움직이기.
- **GitHub Pages로 배포** — 저장소 Settings → Pages에서 배포하고 README에 플레이 링크 추가.
