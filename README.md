# 🚀 미니 슈팅

떨어지는 적을 맞혀 점수를 얻는 간단한 브라우저 슈팅 게임이에요.
설치할 것 없이 HTML·CSS·JavaScript 파일 세 개로 만들어져 있어서, 웹 개발과 GitHub 협업을 연습하기 좋아요.

## 플레이 방법

| 동작 | 키보드 | 휴대폰 |
| --- | --- | --- |
| 이동 | `←` `→` 또는 `A` `D` | ◀ ▶ 버튼 |
| 발사 | `Space` | 발사 버튼 |
| 일시정지 | `P` 또는 `Esc` | 오른쪽 위 ⏸ 버튼 |
| 소리 켜기/끄기 | `M` | 오른쪽 위 🔊 버튼 |
| 다시 시작 | `Enter` 또는 `R` | 다시 시작 버튼 |

- 적을 맞히면 10점, 주황색 단단한 적(두 번 맞혀야 함)은 25점이에요.
- 적과 부딪히거나 적이 바닥에 닿으면 목숨이 하나 줄어요. 맞은 뒤 잠깐은 무적이에요.
- 150점마다 레벨이 올라가고 적이 더 빠르고 많아져요.
- 최고 점수는 브라우저에 저장돼요.

## 실행하기

1. 이 저장소를 내려받아요. (아래 [같이 만들기](#같이-만들기) 참고)
2. `index.html` 파일을 더블클릭해서 브라우저로 열면 끝!

> 💡 VS Code를 쓴다면 **Live Server** 확장을 설치하고 `index.html`에서 "Open with Live Server"를 누르면, 파일을 저장할 때마다 브라우저가 자동으로 새로고침돼서 편해요.

## 파일 구조

```
game/
├── index.html   화면 구조 (점수판, 시작/일시정지/종료 화면, 터치 버튼)
├── style.css    디자인 (색상, 크기, 모바일 화면 대응)
├── game.js      게임 로직 (이동, 충돌, 점수, 효과음, 그리기)
└── CONTRIBUTING.md  같이 작업하는 방법
```

처음 코드를 볼 때는 `game.js` 맨 위의 `CONFIG`부터 보세요. 숫자만 바꿔도 게임이 달라져요.

```js
const CONFIG = {
  lives: 3,           // 목숨 개수
  playerSpeed: 5.5,   // 비행기 속도
  fireCooldown: 12,   // 발사 간격 (작을수록 빨리 쏴요)
  ...
};
```

## 같이 만들기

이 프로젝트는 GitHub로 같이 작업하는 연습을 하려고 만들었어요.
브랜치 만들기 → 수정 → Pull Request → 리뷰 → 머지 순서는 **[CONTRIBUTING.md](CONTRIBUTING.md)** 에 단계별로 정리되어 있어요.
뭘 만들지 고민된다면 **[docs/ISSUE_IDEAS.md](docs/ISSUE_IDEAS.md)** 에서 골라 보세요.
